# Rental Pro v9 Professional Preview

This is the public online preview for Rental Pro v9 Professional.

## Online Preview

https://rami885.github.io/rent-ai-preview/

## What is included

- Fast demo login by role
- Arabic / English interface
- Dashboard, tenants, payments, bills, old balances, expenses, deposits
- Cash flow, journal, ledger, profit and loss
- WhatsApp queue, Wekan tasks, automation, users, and audit log

## Important

This public repository contains the browser preview only.

- Demo only
- Browser storage only
- No Laravel backend included here
- Production backend remains in the private `rent-ai` repository
